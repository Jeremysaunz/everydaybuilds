# Café First Day 영어 화면 현지화

- 목적: 영어 글의 본문 캡처 네 장, 홈·목록 대표 이미지, 체험·다운로드 화면의 언어를 영어로 맞춘다.
- 방식: 이미지에는 기본 내장 ImageGen의 text-localization 편집을 사용했다. API/CLI 모드는 사용하지 않았다.
- 원본: public/images/cafe-first-day/의 한국어 캡처를 유지했다. HTML 원본은 이후 다국어 전환 작업에서 content/tools/cafe-first-day.ko.html에 보존했다.
- 파생 이미지: public/images/cafe-first-day/en/01-first-result.png, 03-training-flow.png, 05-before-cup.png, 06-interactive-cup.png.
- 영어 게임: public/tools/cafe-first-day-en.html. content/tools/cafe-first-day.en.json과 scripts/localize-cafe-game.py에서 관리한다.
- 각 캡처는 당시 한국어 화면의 영어 번역 이미지다. 당시부터 영어 UI가 있었다는 의미로 사용하지 않는다. 영어 글에 번역 이미지임을 표시했다.
- 현재 두 HTML 파일은 모두 파일 내 한국어·영어 전환을 제공한다. 변경 사항과 확인 범위는 docs/cafe-bilingual-html.md에 기록했다.
- 이미지 확인: 점수 1/98/98, 주문 #01/#03, 1/3 및 3/3 진행 상태, 제조 전과 컵 추가 후의 차이를 유지했다. 첫 이미지의 상단 안내·좌측 주의 문구·푸터가 원본과 다르게 번역된 부분은 수정했다.
