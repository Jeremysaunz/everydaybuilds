# 이런나 개발기 1편 블로그 반영

작업일: 2026-10-16. 사용자의 요청으로 이런나 연재 1편을 Everyday Builds의 세 번째 이야기로 한국어·영어 등록했다. 로컬 반영이며 커밋·푸시·배포는 수행하지 않는다.

## 반영 범위

- 한국어: `/ko/builds/ireonna-build-log`
- 영어: `/en/builds/ireonna-build-log`
- 제품 원고: `글/ko.md`, `글/en.md`
- 블로그 이야기 번호는 03, 이런나 연재 회차는 01이다.
- 이런나는 개발 중이다. 완성 도구 수에 추가하지 않으며, 토스 출시나 실기기 검증을 완료한 것으로 표시하지 않는다. 공개 체험·HTML 다운로드 링크도 등록하지 않는다.
- 연재 2편은 `글/02-기질이름과설명/ko.md`에 그대로 두고 게시하지 않는다. 1편의 미발행 후속 편 링크는 공개 본문에서 제외했다.
- 개발일 2026-10-15, 기록·원고 수정일 2026-10-16을 구분한다. 실제 공개 배포일을 미리 기록하지 않는다.

## 이미지

한국어 본문은 원본 초기 홈 JPG(360×780)와 앱에서 출력한 예시 대화 카드 PNG(1280×1108)를 사용한다. 기존 이미지 15개는 원본 해시를 유지한다. 이번에 공개 폴더로 복사하는 것은 이 두 원본과 새 파생 이미지 네 개뿐이다.

영어 본문은 `en/01-home-reading.jpg`(440×1022), `en/02-conversation-card-reading.jpg`(1280×1108)를 사용한다. 원본 화면의 내용을 영어로 옮겨 HTML/CSS로 구성하고 브라우저에서 캡처한 **번역 참고 이미지**다. 실제 앱의 영어판이나 과거 영어 화면의 재캡처가 아니다. 이미지 내부와 본문 캡션에 이를 명시한다.

`03-cover.jpg`와 `en/03-cover.jpg`는 두 화면을 조합한 1280×720 편집 표지다. 원본 개발 캡처로 취급하지 않는다.

제작 소스는 `이미지/_source/first-post-assets.html`이다. `home-en`, `card-en`, `cover-ko`, `cover-en` 쿼리 화면을 로컬 브라우저에서 캡처한다. 영어 홈과 카드를 먼저 저장한 뒤 표지를 만든다. 날짜·출처·해시는 기존 `capture-manifest.json`과 새 `first-post-image-derivatives.json`에 나누어 보관한다.

## 반영 방법

작업 공간 루트에서 `python3 scripts/sync-site.py --apply --product 03`을 실행하고 `python3 scripts/sync-site.py --check`로 원고·이미지·검토 기록의 공개용 복사본이 일치하는지 확인한다.

홈·목록·RSS·사이트맵은 게시 목록을 사용하므로 새 글이 함께 포함된다. 검색용 제목에는 실제 내용인 앱인토스·Codex·기질 테스트 앱을 사용하고, 본문 제목은 개인 개발기의 말투를 유지한다.

## 확인 결과

`npm run lint`, `npm run build -- --webpack`, `git diff --check`를 통과했다. 한영 새 글을 포함한 정적 페이지 24개를 생성했고, 로컬 검색 검사에서 18개 한영 페이지의 메타데이터·언어 링크·구조화 데이터, RSS 3편, 사이트맵 22개 주소와 기존 도구 링크를 확인했다.

브라우저에서 홈의 첫 카드 → 세 번째 이야기 → 같은 글의 영어판 전환을 확인했다. 한영 본문은 320px 화면에서 문서 폭이 320px로 유지된다. 한국어 강조 구문이 별표로 보이던 부분과 목차의 어색한 글자 단위 줄바꿈을 정리했다. 실제 토스 앱이나 개발 중인 이런나의 기능을 이번 블로그 반영 작업에서 새로 검증한 것은 아니다.

## Everyday Builds 관점 재검토

이후 사용자가 다른 제품 프로젝트에서 가져온 원고의 목적과 어조를 다시 검토해 달라고 요청했다. 변경 전 한영 원고는 `_보관/20261016-블로그컨셉수정전/`에 남겼다.

기능과 기획 의도를 설명하는 비중을 줄이고, 기존 두 도구 → 가지고 있던 자료 → 기획 문서를 Codex에 전달 → 나온 화면과 문장을 읽으며 판단 → 기질 이름을 다시 손보기로 한 흐름으로 바꿨다. PRD는 이번에 AI에게 건넨 자료로 짧게 설명했다. 뒤 편에서 다룰 기질 조합과 전통 명칭의 세부 설명은 덜어냈다.

실제 인용 요청 두 개와 이미지·캡션, 개발일, 예시 입력 여부, 미출시 상태는 유지했다. 새 오류나 사용자 반응을 보태지 않았다. 한국어·영어 본문과 홈·검색용 요약을 같은 관점으로 맞췄으며 제목과 URL은 유지한다. 원고 개선을 실제 독자 반응이나 앱 효용 검증으로 해석하지 않는다.

## 관심 있던 아이디어에서 시작하는 흐름으로 수정

2026-10-16 사용자 요청에 따라 기존 테스트(MyEnergyType)와 강의 자료를 갖고 있었다는 소개를 공개 본문에서 덜어냈다. 평소 관심 있던 기질 테스트로 앱을 만들어 보자는 생각에서 시작하며, 모르는 부분은 AI와 대화하며 구체화하는 관점으로 한영 본문을 맞췄다. 기존 자료의 이력이나 실제 요청을 새로 만들어 쓰지는 않았다.

이번 글에서 가져갈 포인트는 막연한 아이디어를 사람이 눌러 볼 순서와 받아 갈 결과로 풀어 AI에게 설명하고, 그 순서대로 나온 화면을 확인하는 것이다. 별도의 강의·팁 상자를 추가하지 않고 기획 문서와 브라우저 확인 장면, 마무리에 녹였다. 제목·홈/검색 요약·한영 표지도 같은 관점으로 수정했다. 기존 검색용 제목과 URL, 요청 인용 두 개, 본문 이미지·캡션, 미출시 안내는 유지한다.

수정 전 원고·표지·제작 소스와 파생 이미지 기록은 `_보관/20261016-아이디어도입수정전/`에 보관했다. 후속 2·3편은 초안으로 유지한다. 이번 수정은 로컬 반영이며 커밋·푸시·배포는 하지 않는다.

이번 수정 검증: 원본 요청 인용 두 개·본문 이미지와 캡션·네 개의 목차 앵커를 유지했고, 파생 이미지 해시와 후속 편의 초안 상태를 확인했다. `npm run build -- --webpack`과 로컬 `verify-seo.mjs`(한영 18개 페이지)를 통과했다. 브라우저에서 새 제목·도입·한영 전환·기획서 이전부터 AI와 아이디어를 정리할 수 있다는 문장을 확인했다.

## 앱인토스 조사와 아이디어 상담부터 시작한 경위 반영

2026-10-16 사용자가 앱인토스를 처음에는 몰랐으며 AI로 조사하고, 공식 홈페이지·개발 가이드 링크를 건네 읽어 보게 한 뒤 만들 아이디어를 물었다고 직접 설명했다. 이 경험을 도입과 1절에 반영했다. 구체적인 과거 추천 목록이나 답변 전문은 현재 보관 자료에서 확인하지 못했으므로 만들지 않았다. 새 질문 인용은 사용자 설명을 바탕으로 취지를 요약한 문장임을 한영 본문에서 표시했다. 기존의 개발 요청 두 개와 화면·예시 캡션은 유지한다. 이전 원고는 `_보관/20261016-앱인토스조사반영전/`에 남겼다.

중심 포인트는 AI와의 대화를 조사·아이디어 선택 단계부터 시작할 수 있다는 점이다. 이전 원고의 ‘지금 다시 시작한다면’이라는 가정은 실제 경험 설명으로 대체했다. 공식 안내를 확인해 유료 기능·콘텐츠를 위한 인앱 결제와 광고를 소개하되, 이런나는 미출시이며 결제·광고 적용과 매출 검증은 하지 않았음을 구분했다. 수익 예상액·수수료·출시 소요 기간은 기재하지 않는다.

확인한 공식 출처: [앱인토스](https://toss.im/apps-in-toss), [개발자 가이드](https://developers-apps-in-toss.toss.im/), [인앱 결제](https://developers-apps-in-toss.toss.im/guide/monetization/in-app-payment), [인앱 광고](https://developers-apps-in-toss.toss.im/guide/monetization/in-app-ad). 한영 제목과 표지는 기질 테스트 앱을 만들기 시작한다는 현재 내용과 맞으므로 유지하고, 본문·홈·검색 요약을 갱신했다. 2·3편 초안과 앱 원본은 수정하지 않으며 커밋·푸시·배포는 수행하지 않는다.

이번 재작성 검증: 빌드(24개 정적 페이지 생성), 한영 18개 페이지의 검색·언어·이미지·피드 검증, 원본 요청·본문 이미지·캡션·날짜 보존 검사를 통과했다. 브라우저에서 한국어 조사 단락과 요약 요청문, 공식 수익화 링크, 영어판의 같은 관점과 미출시 안내를 확인했다.

## 비개발자가 편하게 읽을 수 있도록 문장 전체 재편집

2026-10-16 사용자가 플랫폼 소개처럼 딱딱한 어조와 같은 뜻을 반복하는 설명을 지적했다. 정의·기능 설명보다 알아보고 물어보고 눌러 본 행동으로 한영 본문을 다시 썼다. PRD 약어를 본문에서 덜고 ‘만들고 싶은 모습을 적은 기획 문서’로 설명했다. 소제목과 홈·검색용 요약도 같은 말투로 맞췄다. 교훈을 발표하듯 끝내던 문장은 ‘뭘 만들어 볼까부터 AI와 이야기해도 됐다’는 개인적인 소감으로 바꿨다. 사실·세 인용 요청·공식 링크·본문 이미지와 캡션·날짜·미출시 상태는 유지한다. 수정 전 원고는 `_보관/20261016-편한말투수정전/`에 있다.

이번 문장 수정 검증: 원본 세 요청·두 이미지와 캡션·제목·링크·날짜를 대조해 유지했으며 후속 편은 초안 상태다. 빌드와 한영 18개 페이지 검증을 통과했다. 브라우저에서 첫 설명 단락·네 개의 소제목과 앵커·PRD 약어 제거·한영 전환을 확인했다. 커밋·푸시·배포는 하지 않았다.
