# 카페 첫날 한국어 글 점검과 수정안 (2026-10-15)

대상: `content/posts/cafe-first-day/ko.md` (현재 공개 중인 글)
기준 독자: 30~40대 일반인. AI는 질문·검색용으로만 써 본 사람. 목표는 "나도 AI로 내게 필요한 걸 만들어 볼 수 있겠다"는 흥미와 도전.

이 문서의 수정안은 아직 공개 글에 반영하지 않았다. `[확인: ...]` 자리는 코치님의 실제 경험으로만 채울 수 있는 부분이다. 지어내지 않고 비워 두었다.

**반영 기록 (10/15)**: 코치님 답변(사용한 AI는 ChatGPT, 짬 날 때 1시간 이내, 대화 3~4번, 카페에 있다가 갑자기 떠올림)을 넣어 `ko.md`, `en.md`, `lib/posts.ts`(제목·검색 제목·요약·수정일·사용 도구), README 제목에 반영했다. 로컬 확인까지 마쳤고 배포 전이다. 답이 없던 항목은 이렇게 처리했다. 막힌 장면 단락은 빼고 팁만 "완벽한 계획 없이" 단락에 붙였다. 비용 줄, 첫인상 문장, 결과를 처음 본 방법, "코드는 한 줄도 직접 쓰지 않았어요", "세 번째 요청문은 원문 그대로" 문장은 넣지 않았다. 파일 여는 법은 ChatGPT의 일반적인 안내로 썼다.

---

## 1. 총평

어조와 정직함은 이미 좋다. 해요체가 부드럽고, HTML 같은 낯선 말을 친절하게 풀었고, 실제 요청문과 전후 화면을 보여 줘서 믿음이 간다. 과장이 없다.

부족한 것은 **"나도 할 수 있겠다"의 근거**다. 독자가 실제로 따라 하려는 순간 필요한 정보(어떤 AI를 썼는지, 얼마나 걸렸는지, 돈이 드는지, 결과 파일을 어떻게 여는지, 막혔을 때 어떻게 했는지)가 빠져 있다. 또 소재가 카페라서 대부분의 독자에게는 "남의 이야기"로 읽힐 수 있다. 글이 고요하고 매끄러워서 읽기는 편하지만, 읽고 나서 바로 해 보고 싶어지는 힘은 약하다.

## 2. 항목별 점검

| 항목 | 현재 | 판단 |
|:--|:--|:--|
| 어조 | 해요체, 차분하고 친근함 | 좋음. 다만 문장 끝이 "~했어요"로 단조롭고, 설렘이나 놀라움이 거의 없음 |
| 낯선 용어 | HTML을 "브라우저로 여는 파일 하나"로 설명 | 좋음 |
| 정직함 | 실제 매장 도입 아님, 요청문 다듬음을 밝힘 | 좋음. 유지 |
| 공감 | 소재가 카페 신입 교육 | 약함. 독자 대부분이 카페와 무관. 내 일로 옮겨 생각하게 하는 다리가 없음 |
| 따라 할 근거 | 사용한 AI·시간·비용·막힌 지점 없음 | **가장 큰 약점.** "파일을 만드는 방법은 사용하는 AI에 따라 조금씩 달라요"에서 초보 독자가 멈춤 |
| 도입부 | 여행지·맛집 질문 이야기로 시작 | 공감은 되지만 "그게 돼?" 하는 순간이 없음. "코딩 몰라도"가 앞에 와야 함 |
| 흐름 | 첫 결과 직후 "왜 HTML 파일로 만들었을까요?" 3단락 | 이야기가 끊김. 메신저 공유 방법까지 들어가 곁가지가 됨. 뒤쪽 실전 안내로 옮기고 줄임 |
| 주의 문구 | "담당자가 먼저 확인", "실제 양은 매장 레시피" 두 번 | 카페 사장이 아닌 독자에게는 흥미를 깎음. 한 번만, 짧게 |
| 핵심 메시지 | "처음부터 모든 기능을 다 생각해두진 않았어요" | 가장 좋은 메시지인데 제목과 첫 문장이 같은 말을 반복해 힘이 약함 |
| 마무리 행동 | 여행 준비물 예시 1개 | 좋지만 하나뿐. 30~40대 일상(아이, 모임, 집안일) 예시와 "요청문 틀"이 있으면 바로 시도 가능 |
| 제목·검색 | 제목 맨 앞이 "카페 신입 교육" | 대상 독자의 검색어("바이브 코딩", "코딩 없이", "ChatGPT로 만들기")와 어긋남. 인스타 캡션에는 #바이브코딩을 썼는데 블로그 본문에는 이 말이 한 번도 없음 |
| 기획 기준 | 기획 노트는 "같은 요청문을 ChatGPT와 Claude에 함께" | 이 글은 어떤 AI를 썼는지도 밝히지 않음. 최소한 사용한 AI 이름은 넣어야 함 |

## 3. 코치님께 확인할 것 (수정안의 빈칸)

아래 답만 주시면 수정안을 완성해 공개 글에 반영할 수 있다. 1~3번이 가장 중요하다.

1. **사용한 AI**: ChatGPT, Claude, 둘 다 중 무엇인가요? 요금제(무료/유료)는?
2. **걸린 시간과 대화 횟수**: 대략 몇 시간, 몇 번 주고받았나요?
3. **막혔던 순간 하나**: 원하는 대로 안 나왔거나 오류가 난 장면이 있었나요? 뭐라고 다시 말했고 어떻게 풀렸나요? (없었다면 이 단락은 빼고 팁으로만 둔다)
4. **결과를 처음 본 방법**: AI 화면의 미리보기로 바로 눌러 봤나요, 파일을 받아 열었나요?
5. **첫 결과를 봤을 때 실제 느낌** 한 줄
6. **왜 카페 교육이었는지** 한두 문장 (선택. 없어도 글은 성립함)
7. **코드를 직접 고친 적이 있는지**: 한 번도 없다면 "코드는 한 줄도 직접 쓰지 않았어요"를 넣는다
8. **세 번째 요청문**("그런 식으로도 만들어줘요")이 실제 보낸 문장 그대로가 맞는지
9. (선택) **실제 AI 대화창 캡처 1장**: 첫 요청을 보낸 화면이 있으면 "이 정도만 쓰면 되는구나"를 눈으로 보여 줄 수 있다

|:--|:--|:--|
| 제목 | 카페 신입 교육 게임을 말로 부탁해 만들었어요 | **코딩 몰라도, 말로 부탁해서 카페 교육 게임을 만들었어요** |
| 검색 제목 | AI로 카페 신입 교육 게임 만들기: HTML 음료 제조 연습 | 바이브 코딩 첫 도전: 코딩 없이 AI로 카페 신입 교육 게임 만들기 |
| 요약 | AI에게 말로 부탁해 카페 신입 교육 게임을 만들었어요. 직접 해보며 필요한 내용을 더하고, 컵에 재료를 넣는 화면으로 바꿔 봤어요. | 코딩을 몰라도 AI에게 말로 부탁하면 직접 눌러 쓰는 도구를 만들 수 있어요. 실제로 보낸 요청문과 바뀐 화면, 오늘 바로 써 볼 첫 요청문 예시까지 정리했어요. |

다른 제목 후보:
- 채팅만 하던 AI에게 "게임 하나 만들어 줘"라고 해 봤어요
- 바이브 코딩 첫 도전: 말로 부탁해 만든 카페 신입 교육 게임
- (사용한 AI가 확인되면) ChatGPT에게 말로 부탁해서 카페 교육 게임을 만들었어요

주소(slug)는 `cafe-first-day` 그대로 둔다. 이미 구글·네이버에 등록했기 때문이다.

## 5. 고친 점 요약

1. 도입: "코딩 몰라도", "말하고 → 눌러 보고 → 다시 말하기"를 첫 화면에 올리고, '바이브 코딩'을 한 번 쉽게 소개했다.
2. "이번 제작 한눈에 보기"를 넣어 AI·시간·비용·결과물을 먼저 보여 준다. (빈칸 4개)
3. "카페 일을 하지 않아도 괜찮아요" 단락으로 독자가 자기 일(아이 등교 준비, 부모님 휴대폰 안내, 회사 신입 설명)을 대입하게 했다.
4. "왜 HTML 파일로 만들었을까요?"를 뒤쪽 실전 안내로 옮기고 절반으로 줄였다.
5. 주의 문구 두 번을 한 번으로 합쳤다. (교육 흐름 단락 끝 한 문장, 컵 이미지 설명 한 문장)
6. "막힌 순간도 있었어요" 단락을 새로 두었다. (실제 경험으로 채울 빈칸)
7. 세 번째 요청문이 다듬지 않은 실제 문장이라는 점을 살려 "이 정도로 편하게 말해도 된다"를 보여 준다.
8. 핵심 메시지를 "말한다 → 써 본다 → 아쉬운 점을 다시 말한다" 한 줄로 고정했다.
9. 요청문 틀(누가·언제·무엇을·어떻게)과 30~40대 일상 예시 3개(여행 준비물, 아이 등교 체크판, 모임 회비 정산)를 넣었다. 회비 정산과 칭찬 스티커판은 20편 기획에도 있는 주제라 다음 글로 이어지기 좋다.
10. 마무리를 "오늘 저녁, 하나만 부탁해 보세요"로 바꿔 첫 행동을 분명히 했다.

반영할 때 함께 할 일: 영어판 `en.md`도 같은 구조로 맞춘다. `lib/posts.ts`의 제목·검색 제목·요약을 바꾸고, `updatedAt`을 갱신한다. 본문에 목록(-)을 쓰면 현재 글 스타일에 목록 모양이 없으므로, 수정안은 목록 없이 썼다.

## 6. 수정안 전문

아래가 `ko.md`를 바꿀 원고다. 첫 줄 제목은 화면에서 `lib/posts.ts`의 제목으로 표시된다.

```markdown
# 코딩 몰라도, 말로 부탁해서 카페 교육 게임을 만들었어요

AI에게 맛집을 묻거나 메일 문장을 다듬어 달라고 해 본 적은 있으시죠? 그럼 “이런 프로그램 하나 만들어 줘”라고 부탁해 본 적은요?

저도 한동안은 AI에게 묻고 답을 받는 데만 썼어요. 그러다 평소에 “이런 게 하나 있으면 편할 텐데” 하고 지나쳤던 것들을 AI에게 직접 만들어 달라고 해 보기로 했어요.

첫 번째로 만든 건 **카페 신입 직원이 음료 만드는 순서를 연습하는 게임**이에요. 제가 한 일은 세 가지예요. 원하는 걸 말로 설명하고, 나온 화면을 눌러 보고, 아쉬운 점을 다시 말하기. [확인: 코드는 한 줄도 직접 쓰지 않았어요.]

요즘은 이런 방식을 **바이브 코딩**이라고 부르더라고요. 코드를 짜는 대신 “이런 느낌으로 만들어 줘”라고 말로 전하면, 코드는 AI가 써 주는 방식이에요. 개발자가 아니어도 시작할 수 있다는 게 핵심이에요.

완성된 게임은 이 글 맨 위 **게임 직접 해보기**에서 바로 눌러 볼 수 있어요. 한 판 해 보고 읽으시면 이야기가 더 잘 보일 거예요.

### 이번 제작 한눈에 보기

**사용한 AI** [확인: 예) ChatGPT 유료 요금제]

**걸린 시간** [확인: 예) 저녁에 두 시간쯤, 대화는 열 번 남짓]

**비용** [확인: 예) 쓰던 요금제 그대로, 추가 비용 없음]

**결과물** 인터넷 창(브라우저)으로 여는 파일 하나. 설치할 것도, 가입할 것도 없어요.

## 카페 일을 하지 않아도 괜찮아요

[확인(선택): 카페 교육을 고른 이유 한두 문장]

카페에서 일을 시작하면 음료마다 만드는 순서부터 익혀야 해요. 주문을 읽고, 컵을 고르고, 어떤 재료를 먼저 넣는지 기억해야 하죠. 이걸 게임처럼 연습할 수 있으면 좋겠다고 생각했어요.

카페에서 일하지 않는 분도 이 이야기를 그대로 가져가실 수 있어요. **순서를 익혀야 하는 일**은 어디에나 있거든요. 아이가 아침마다 하는 등교 준비, 부모님께 몇 번이고 알려 드리는 휴대폰 사용법, 회사에 신입이 올 때마다 반복하는 설명 같은 것들이요. 읽는 동안 ‘카페’ 자리에 여러분의 그 일을 넣어 보세요.

## 첫 부탁: 하고 싶은 걸 그대로 말했어요

처음에는 이런 뜻으로 요청했어요.

> 카페에 신입 직원이 들어왔을 때 음료 만드는 순서를 게임처럼 연습할 수 있게 만들고 싶어요. HTML 파일 하나로 열어 쓸 수 있게 만들어 주세요.

HTML이라는 말이 낯설어도 괜찮아요. **인터넷 창으로 여는 파일 하나**라고 생각하시면 돼요. 앱처럼 설치할 필요 없이, 파일을 열면 바로 화면이 떠요.

[확인: 결과를 처음 본 방법 한 줄. 예) 답변 옆 미리보기 창에서 바로 눌러 볼 수 있었어요.]

첫 결과는 이렇게 나왔어요.

![처음 만들어진 카페 교육 게임](/images/cafe-first-day/01-first-result.png)

*주문표를 읽고, 컵을 고르고, 음료 만드는 순서를 맞히는 첫 화면이에요.*

[확인: 이 화면을 처음 봤을 때의 실제 느낌 한 줄]

머릿속에만 있던 생각이 실제로 눌러 볼 수 있는 화면이 됐어요. 화면이 생기니 그제야 다음 질문이 떠올랐어요. 처음 쓰는 사람에게 이걸로 충분할까?

## 모르는 건 AI에게 같이 봐 달라고 했어요

저는 카페 신입 교육을 잘 아는 사람이 아니에요. 음료 순서만 연습하면 되는지, 처음 쓰는 사람이 헤매지는 않을지 확신이 없었어요. 그래서 그 고민을 그대로 넘겼어요.

> 신입 직원을 위한 교육에서 빠진 부분이 있는지 확인해 주세요. 더 편리하게 쓸 수 있도록 해 주고, 디자인도 함께 다듬어 주세요.

![교육 흐름을 보완한 시작 화면](/images/cafe-first-day/03-training-flow.png)

*기본기를 배우고, 매장 레시피를 읽은 뒤, 음료를 만들어 보는 흐름이 생겼어요.*

연습할 메뉴를 고르고, 단계별로 따라 배우거나 혼자 풀어 볼 수 있게 바뀌었어요. 주문 확인, 위생, 실수했을 때 대처하는 연습도 들어갔고요.

여기서 배운 게 있어요. **내가 그 분야 전문가가 아니어도 괜찮다**는 거예요. 누가 쓸 도구인지 설명하고 “빠진 게 있으면 봐 줘”라고 하면, AI가 빠진 부분을 먼저 챙겨 주기도 해요. 다만 실제 교육에 쓰려면 매장 담당자가 내용을 한 번 확인해야 해요.

## 눌러 보다가 떠오른 한마디

이때까지는 글로 된 버튼을 골라 순서를 맞히는 방식이었어요.

![글로 제조 순서를 고르던 화면](/images/cafe-first-day/05-before-cup.png)

*이때는 재료를 넣는 대신, 다음에 할 일을 글로 골랐어요.*

그 화면을 보다가 아쉬운 점이 하나 생겼어요. 컵 안에 얼음이 쌓이고 우유와 샷이 들어가는 게 눈에 보이면 훨씬 게임 같을 것 같았거든요. 그래서 느낀 그대로 말했어요.

> 컵에 얼음이나 우유, 샷을 직접 넣으면서 음료가 만들어지는 모습이 눈에 보이면 더 게임 같을 것 같아요. 그런 식으로도 만들어줘요.

이 요청은 다듬지 않은 실제 문장이에요. 친구에게 말하듯 편하게 써도 충분히 알아들어요.

![컵에 얼음, 우유와 샷을 넣은 화면](/images/cafe-first-day/06-interactive-cup.png)

*재료를 누르거나 컵으로 끌어 넣으면 음료가 만들어져요. 컵의 양과 색은 과정을 보여 주는 그림이고, 실제 양은 매장 레시피를 따라요.*

얼음을 넣으면 얼음이 쌓이고, 우유와 샷을 넣으면 컵 안에 색과 층이 생겨요. 순서를 틀리면 컵을 비우고 다시 만들면 돼요. 글자 버튼을 고르던 화면이, 한마디 부탁으로 손으로 만지는 게임이 됐어요.

## 막힌 순간도 있었어요

[확인: 실제로 막혔던 장면 하나. 무엇이 안 됐고, AI에게 뭐라고 말했고, 어떻게 풀렸는지 두세 문장. 없었다면 이 단락을 빼고 아래 팁만 다음 단락에 붙인다.]

막혔을 때 코드를 몰라도 괜찮아요. **본 그대로, 겪은 그대로 말하면 돼요.** “버튼을 눌러도 아무 반응이 없어요”, “휴대폰에서 글씨가 너무 작아요”처럼요.

## 완벽한 계획 없이 시작해도 돼요

처음부터 기본기 문제나 컵에 재료를 넣는 기능까지 생각해 둔 건 아니었어요. 화면을 보고 나니 다음에 부탁할 말이 떠올랐어요.

바뀔 때마다 직접 눌러 봤어요. 재료가 제대로 들어가는지, 컵을 비우고 다시 만들 수 있는지, 잠시 멈췄다가 이어서 할 수 있는지요. 이 글에서 한 일을 정리하면 이 세 가지의 반복이에요.

**말한다 → 써 본다 → 아쉬운 점을 다시 말한다**

처음부터 다 정해 두지 않아도 돼요. 첫 부탁 하나만 있으면, 다음에 할 말은 화면이 알려 줘요.

## 여러분의 첫 부탁, 이렇게 시작해 보세요

늘 반복하는 설명이나 종이에 적어 두는 체크표 하나를 떠올려 보세요. 그리고 네 가지만 담아 말하면 돼요.

**누가** 쓰나요? **언제** 쓰나요? **무엇을** 할 수 있으면 좋겠나요? **어떻게** 열고 싶나요?

예를 들면 이렇게요.

> 가족이 여행 전에 같이 확인할 준비물 체크표를 만들고 싶어요. 물건을 추가하고, 챙긴 것은 체크할 수 있으면 좋겠어요. 휴대폰 브라우저에서 열어 쓸 수 있는 HTML 파일로 만들어 주세요.

> 초등학생 아이가 아침마다 혼자 등교 준비를 할 수 있게 체크판을 만들고 싶어요. 양치, 옷 입기, 가방 챙기기를 하나씩 누르면 칭찬 문구가 나오면 좋겠어요. 아이가 누르기 쉽게 버튼을 크게, 브라우저에서 열 수 있는 HTML 파일로 만들어 주세요.

> 모임 회비를 정산하는 계산기가 필요해요. 사람 수와 쓴 돈을 넣으면 한 사람당 낼 금액이 나오고, 결과를 단톡방에 붙여 넣기 쉽게 복사 버튼이 있으면 좋겠어요. HTML 파일 하나로 만들어 주세요.

결과가 나오면 바로 열어 보세요. 휴대폰에서 글씨가 작으면 “글씨와 버튼을 더 크게 해 주세요”, 색이 마음에 안 들면 “좀 더 차분한 색으로 바꿔 주세요”라고 이어서 말하면 돼요.

### 만든 파일은 어떻게 열고 나누나요

[확인: 쓰신 AI 기준으로 한두 문장. 예) ChatGPT나 Claude는 대화창에서 결과 화면을 바로 보여 주거나 파일로 내려받게 해 줘요. 화면이 안 보이면 “내려받을 수 있는 HTML 파일로 주세요”라고 말해 보세요. 받은 파일을 더블클릭하면 인터넷 창에서 열려요.]

HTML 파일은 인터넷 창만 있으면 컴퓨터에서도 휴대폰에서도 열려요. 메신저로 파일을 보내도 되지만, 휴대폰은 앱마다 파일을 여는 방식이 달라요. 여러 사람에게 나눌 때는 웹에 올려 링크로 보내는 게 편해요.

## 오늘 저녁, 하나만 부탁해 보세요

AI는 질문에 답만 해 주는 게 아니라, 내게 필요한 작은 도구를 같이 만들어 주기도 해요. 늘 말로 하던 설명은 눌러 보는 화면으로, 종이에 적던 체크표는 손가락으로 체크하는 목록으로 바꿔 볼 수 있어요.
```
