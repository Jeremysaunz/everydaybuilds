# 바이브코딩 입문: ChatGPT로 카페 교육 게임 만들기

AI에게 맛집을 묻거나 메일 문장을 다듬어 달라고 해 본 적은 있으시죠? 그럼 “이런 프로그램 하나 만들어 줘”라고 부탁해 본 적은요?

저도 한동안은 챗지피티와 말 그대로 채팅만 했지요. 그것만으로도 훌륭하다고 생각했으니까요.

그러다 평소에 “이런 게 있으면 편하겠다”고 생각했던 프로그램을 직접 만들어 달라고 해 봤습니다.

첫 번째로 만든 건 **카페 신입 직원이 음료 만드는 순서를 연습하는 게임**입니다. 원하는 걸 설명하고, 결과를 직접 눌러 보고, 고칠 점을 다시 말했습니다.

**바이브코딩**이라고 부르죠. 원하는 내용을 말로 설명하면 AI가 코드를 작성해 주는 방식입니다.

완성된 게임은 이 글 맨 위 **게임 직접 해보기**에서 열 수 있습니다.

### 사용한 도구와 제작 시간

**사용한 AI** ChatGPT

**첫 버전 제작 시간** 짬 날 때 한 시간 안쪽

**첫 버전에서 주고받은 대화** 서너 번

**결과물** 인터넷 창(브라우저)에서 여는 HTML 파일 하나. 별도 설치나 가입은 필요 없습니다.

## 자주 가던 카페에서 떠올린 생각

이 아이디어는 제가 자주 가던 카페에 있다가 갑자기 떠올랐어요.

카페에 신입 직원이 들어오면 음료마다 만드는 순서를 익혀야 합니다. 주문을 읽고, 컵을 고르고, 어떤 재료를 먼저 넣는지 기억해야 하죠. 이 순서를 게임으로 연습하면 좋겠다는 생각이 들었습니다.

아이의 등교 준비나 부모님의 휴대폰 사용법, 회사 신입에게 알려 줄 업무 순서도 비슷합니다. 모두 **순서를 익혀야 하는 일**이니까요.

## 첫 프롬프트:

처음에는 이런 뜻으로 요청했습니다.

> 카페에 신입 직원이 들어왔을 때 음료 만드는 순서를 게임처럼 연습할 수 있게 만들고 싶어요. HTML 파일 하나로 열어 쓸 수 있게 만들어 주세요.

HTML은 **인터넷 창으로 여는 파일**이라고 생각하시면 됩니다. 앱처럼 설치할 필요 없이 파일을 열면 바로 실행됩니다.

처음 나온 화면입니다.

![처음 만들어진 카페 교육 게임](/images/cafe-first-day/01-first-result.png)

*주문표를 읽고, 컵을 고르고, 음료 만드는 순서를 맞히는 첫 화면입니다.*

일단 게임은 돌아갔습니다. 다만 이것만으로 카페 신입 교육에 쓸 수 있을지는 잘 모르겠더군요.

## 두 번째 프롬프트: 교육 내용 보완

제가 카페 신입 교육을 잘 아는 건 아닙니다. 음료 순서만 연습하면 충분한지, 처음 쓰는 사람이 헤맬 부분은 없는지 함께 살펴봐 달라고 했습니다.

> 신입 직원을 위한 교육에서 빠진 부분이 있는지 확인해 주세요. 더 편리하게 쓸 수 있도록 해 주고, 디자인도 함께 다듬어 주세요.

![교육 흐름을 보완한 시작 화면](/images/cafe-first-day/03-training-flow.png)

*기본기를 배우고, 매장 레시피를 읽은 뒤, 음료를 만들어 보는 흐름이 생겼습니다.*

연습할 메뉴를 고르고, 안내를 따라 배우거나 혼자 풀어 볼 수 있게 바뀌었습니다. 처음 요청에 없었던 주문 확인과 위생, 실수했을 때 대처하는 연습도 추가됐죠.

매장에서 실제 교육에 쓰려면 담당자가 내용을 확인해야 합니다.

## 세 번째 프롬프트: 컵에 직접 재료 넣기

여기까지는 글로 된 버튼을 눌러서 음료 만드는 순서를 고르는 방식이었습니다.

![글로 제조 순서를 고르던 화면](/images/cafe-first-day/05-before-cup.png)

*이때는 재료를 넣는 대신, 다음에 할 일을 글로 골랐습니다.*

그런데 버튼만 누르다 보니 조금 아쉬웠습니다. 얼음이나 우유를 컵에 넣는 모습까지 보이면 더 게임 같겠더군요. 그래서 한 번 더 요청했습니다.

> 컵에 얼음이나 우유, 샷을 직접 넣으면서 음료가 만들어지는 모습이 눈에 보이면 더 게임 같을 것 같아요. 그런 식으로도 만들어줘요.

![컵에 얼음, 우유와 샷을 넣은 화면](/images/cafe-first-day/06-interactive-cup.png)

*재료를 누르거나 컵으로 끌어 넣으면 음료가 만들어집니다. 컵의 양과 색은 과정을 보여 주는 그림이고, 실제 양은 매장 레시피를 따릅니다.*

얼음을 넣으면 컵 안에 쌓이고, 우유와 샷은 서로 다른 색과 층으로 표시됩니다. 순서를 틀리면 컵을 비우고 다시 시작할 수 있습니다. 직접 컵을 채워 가면서 연습하는 게임이 된 거죠.

## 네 번째 프롬프트: 색감을 좀 더 쨍하게

기능을 갖추고 나니 색감이 조금 아쉬웠습니다. 크림색과 연한 초록색이 차분하긴 한데, 게임치고는 좀 밋밋하더군요.

> 색이 좀 밋밋한데, 카페 느낌은 살리면서 색깔이 좀 더 쨍하게 보이게 해 줘요. 버튼이나 실습 화면도 눈에 잘 들어오면 좋겠어요.

![주황색과 파란색으로 바꾼 카페 첫날 시작 화면](/images/cafe-first-day/07-color-home.jpg)

*시작 화면에는 주황색과 파란색을 크게 쓰고, 노란색으로 포인트를 줬습니다.*

바탕은 밝은 크림색으로 두고, 시작 버튼과 선택한 메뉴에는 파란색을 썼습니다. 색이 선명해져도 설명은 편하게 읽을 수 있도록 정리했습니다.

![노란 컵 영역과 파란 재료 영역에서 카페라떼를 만드는 화면](/images/cafe-first-day/08-color-cup.jpg)

*컵을 놓는 곳은 노란색, 재료를 고르는 곳은 연한 파란색으로 나눴습니다. 만드는 순서와 재료를 넣는 기능은 같습니다.*

같은 게임도 색을 바꾸니 인상이 꽤 달라졌습니다. 색을 바꾼 뒤에도 재료 넣기와 음료 완성, 한국어·영어 전환이 잘 되는지 다시 확인했습니다.

## 직접 실행해 보고 수정하기

기본기 문제나 컵에 재료를 넣는 기능은 첫 프롬프트에 없었습니다. 음료 만드는 순서를 고르는 게임으로 시작해서 교육 내용을 보완하고, 컵을 직접 채우는 기능을 더했습니다.

수정할 때마다 직접 실행해 봤습니다. 재료가 제대로 들어가는지, 컵을 비우고 다시 만들 수 있는지, 잠시 멈췄다가 이어서 할 수 있는지 확인했습니다.

문제가 생기면 그 상황을 그대로 적으면 됩니다. “버튼을 눌러도 아무 반응이 없어요”, “휴대폰에서 글씨가 너무 작아요”처럼요.

## 내 도구를 만들 때 적어 볼 것들

자주 설명하는 일이나 종이에 적어 두는 체크표가 있다면, 그중 하나로 시작해 볼 수 있습니다. 첫 프롬프트를 쓸 때는 다음 네 가지를 정리하면 편합니다.

**누가** 쓰나요? **언제** 쓰나요? **무엇을** 할 수 있으면 좋겠나요? **어떻게** 열고 싶나요?

예를 들면 이런 식입니다.

> 가족이 여행 전에 같이 확인할 준비물 체크표를 만들고 싶어요. 물건을 추가하고, 챙긴 것은 체크할 수 있으면 좋겠어요. 휴대폰 브라우저에서 열어 쓸 수 있는 HTML 파일로 만들어 주세요.

> 초등학생 아이가 아침마다 혼자 등교 준비를 할 수 있게 체크판을 만들고 싶어요. 양치, 옷 입기, 가방 챙기기를 하나씩 누르면 칭찬 문구가 나오면 좋겠어요. 아이가 누르기 쉽게 버튼을 크게, 브라우저에서 열 수 있는 HTML 파일로 만들어 주세요.

> 모임 회비를 정산하는 계산기가 필요해요. 사람 수와 쓴 돈을 넣으면 한 사람당 낼 금액이 나오고, 결과를 단톡방에 붙여 넣기 쉽게 복사 버튼이 있으면 좋겠어요. HTML 파일 하나로 만들어 주세요.

### 파일을 열고 공유하는 방법

ChatGPT 답변에 코드가 길게 나왔다면 “내려받을 수 있는 HTML 파일로 주세요”라고 요청하면 됩니다. 받은 파일을 더블클릭하면 브라우저에서 열립니다. Claude 같은 다른 AI에도 같은 방식으로 요청할 수 있습니다.

컴퓨터와 휴대폰 모두 브라우저로 열어 쓸 수 있습니다. 메신저로 파일을 보낼 수도 있지만, 휴대폰은 앱마다 파일을 여는 방식이 다릅니다. 여러 사람에게 보낼 때는 웹에 올려 링크로 공유하는 방법이 편합니다.
