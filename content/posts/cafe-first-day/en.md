# I asked AI to build a café training game

Have you ever asked AI for travel ideas or restaurant recommendations? Asking questions and getting answers has become pretty familiar.

I use AI that way too. Then I started wondering if it could help me build the little tools I often wish I had for everyday tasks.

Everyday Builds is where I try those ideas, one at a time. The first thing I made was **a game to help new café staff practice making drinks**. Here’s what I asked AI to do and how the game changed.

## What if new café staff could practice with a game?

When you start working at a café, there is a lot to remember: how to read an order, which cup to use, and the order in which to add each ingredient.

I thought a game might be a useful way to practice those steps. My first request went something like this:

> I want to make a game that lets new café staff practice the steps for making drinks. Please make it a single HTML file that I can open and use.

If HTML is new to you, think of it as **a file you can open in your web browser**. I wanted someone to be able to open it and start practicing.

### Why did I choose an HTML file?

A short message is often enough to explain something. An HTML file lets you lay out the information with headings and pictures, or add buttons and a checklist. You can also make it easy to read and use on a phone.

**Getting comfortable with HTML files gives you more ways to share information.** You could turn an information sheet into a page that’s easy to read, or a packing list into a checklist people can tap through.

You can send the file through a messaging app that supports attachments. If you put it online, you can share a link in a message or social media post. Apps open HTML files differently on phones, so a link is often easier when sharing with several people.

## I asked AI to help with the parts I knew less about

I don’t know much about training café staff. I wondered whether practicing the steps would be enough, and whether someone new to the game would find it easy to use.

So I asked:

> Please check whether the training is missing anything a new staff member would need. Make the game easier to use and improve the design too.

![The start screen after improving the training flow](/images/cafe-first-day/en/03-training-flow-v2.png)

*Start with the basics, read the café’s recipes, then try making a drink.*

You could now choose which drinks to practice, follow the hints, or try it from memory. There were also short questions about checking orders, keeping things clean, and what to do when something goes wrong.

I explained who the game was for and asked AI to help work out what else they might need.

If a café wants to use the game for training, a trainer should check it first. Making real drinks, keeping things clean, and using the equipment need to be learned at the café.

## Adding ingredients to a cup made it feel more like a game

At this point, you practiced by choosing buttons with the steps written on them. Looking at that screen gave me another idea.

![The practice screen before adding ingredients directly to the cup](/images/cafe-first-day/en/05-before-cup-v2.png)

*You picked what to do next from a set of written options.*

I thought it would feel more like a game if you could see ice fill the cup, followed by milk and espresso. So this time I asked:

> It would feel more like a game if you could put ice, milk, and espresso directly into a cup and see the drink being made. Please make it work that way too.

Here is how the screen changed.

![The cup after adding ice, milk, and espresso](/images/cafe-first-day/en/06-interactive-cup-v2.png)

*Click an ingredient or drag it into the cup to make the drink. The previous screenshot shows an Americano; this one shows a latte.*

The ice piles up in the cup, and the milk and espresso form visible layers. If you get the steps out of order, you can empty the cup and start again.

The cup is only an illustration of how the drink is made. Follow the café’s recipe for the actual amounts.

## I didn’t plan every feature in advance

I hadn’t planned the basics questions or the interactive cup when I first asked. Each version helped me see what to ask for next.

After each change, I tried the game. Could I add ingredients, empty the cup and start again, or take a break and pick up where I left off? I kept trying it and asking for changes.

Think of one small tool that would help in your everyday life. It could be for something you explain over and over, or a checklist you keep on paper. Start with **who will use it, when, and what you’d like them to be able to do**.

For example:

> I want to make a packing checklist my family can use together before a trip. We should be able to add items and check them off as we pack. Please make it a file we can open in a browser.

Ask an AI tool that can create files, then open what it makes and try it. If the text is too small on your phone, ask, “Please make the text and buttons bigger.” How you make and download the file will depend on the AI tool you use.
